# ПРАВИЛА РАЗРАБОТКИ В ПРОЕКТЕ UFANET KABAN

1. **ВСЕГДА читай PROJECT_MAP.md и ARCHITECTURE.md перед действиями.**
2. **Определяй минимальный набор файлов.** Запрещено сканировать весь репозиторий, если компонент указан в `PROJECT_MAP.md`.
3. **Декларируй файлы:** Перед вызовом инструментов редактирования явно перечисли, какие файлы будешь читать и менять.
4. **Не трогай несвязанные файлы.** Изменения должны быть строго локализованы.
5. **Валидация:** Всегда проверяй синтаксис через `npx oxlint` и билд через `npm run build`.
6. **Краткий отчет:** В ответе пользователю фиксируй точный перечень изменений и причину.
