# KABAN WORKFLOW SKILL

Используй этот навык при получении любой задачи по проекту **Ufanet Kaban**.

## Алгоритм работы:
1. **Шаг 1: Консультация с картой.**  
   Открой `PROJECT_MAP.md` и сопоставь запрос пользователя с матрицей ответственности (раздел 2).
2. **Шаг 2: Выбор файлов.**  
   Выбери 1–3 файла, которые отвечают за запрашиваемое поведение. Не открывай всю папку `src/`.
3. **Шаг 3: Точечное чтение.**  
   Читай только нужные диапазоны строк (`read_file` со `StartLine` и `EndLine`).
4. **Шаг 4: Безопасное редактирование.**  
   Вноси изменения только в целевые компоненты. Не меняй сигнатуры общих функций и констант без необходимости.
5. **Шаг 5: Проверка.**  
   Проверяй целостность кода:
   - `npx oxlint <измененные_файлы>`
   - `npm run build`
6. **Шаг 6: Фиксация и отчёт.**  
   Делай коммит с осмысленным сообщением, отправляй в `origin main` и выдавай краткий отчёт пользователю.
