## 2. Матрица ответственности (Где что лежит)

| Функциональная зона | Ответственные файлы | Что здесь происходит |
|---|---|---|
| **Канбан-доска и колонки** | `KanbanColumn.jsx`, `ColumnsModal.jsx`, `App.jsx` | Отображение колонок, лимиты задач, перетаскивание карточек, редактирование этапов |
| **Карточки задач на доске** | `TaskCard.jsx` | Рендер карточки, стикеры, секундомер, выпадающее дерево подзадач, Drag&Drop вложение |
| **Создание/редактирование задачи** | `TaskModal.jsx`, `TaskDetailView.jsx` | Полная форма паспорта проекта, данные ProjectPay (ERP, Кст, Кизм, Ксл), соисполнители |
| **Чат задачи и ТЗ** | `TaskChatPanel.jsx`, `mentions.jsx` | Вкладки «Чат», «Инфо и ТЗ», «Подзадачи», «Файлы», таймер, зеркалирование |
| **Общий чат отдела** | `ChatSidebar.jsx` | Сообщения отдела, прикрепление файлов, ссылки на задачи, закрепленные темы |
| **Сетевые папки и файлы** | `lib/api.js` (`openFolderInExplorer`, `uploadTaskFile`), `server.js` (`/api/open-folder`, `/api/upload`) | Открытие `\\ufanet\dfs\...` в Проводнике Windows, загрузка вложений |
| **Поиск и выбор исполнителей** | `SmartMemberPicker.jsx` | Быстрый поиск по ФИО, должности, отделу с цветными аватарами |
| **Авторизация и гости** | `AuthModal.jsx`, `App.jsx` (Lock Screen), `server.js` (`/api/auth/*`) | Вход по логину/паролю, регистрация, блокировка доски для неавторизованных |
| **Профиль и сотрудники** | `ProfileModal.jsx`, `TeamModal.jsx` | Редактирование профиля инженера, управление составом отдела |
| **Марки / Разделы проекта** | `SectionsModal.jsx`, `lib/constants.js` | Марки (ВДН, МКЖ, ЧС, ККС, СКУД, ОДРС, СВН, ЭОМ) |
| **Права доступа и роли** | `lib/constants.js` (`DEFAULT_PERMISSIONS`, `hasPermission`), `SettingsModal.jsx` | Матрица уровней доступа (1..10), разграничение прав начальников и инженеров |
| **Уведомления и упоминания** | `Header.jsx`, `lib/mentions.jsx`, `server.js` (`/api/notifications`) | Колокольчик, пуши об упоминании `@сотрудник` / `@все`, автокомплит |
| **Сетевой обмен и Realtime** | `server.js`, `lib/api.js` | REST API + Server-Sent Events (SSE) для мгновенной синхронизации между всеми вкладками |

## 3. Ядерные файлы (Nuclear Core — трогать крайне осторожно)

1. `server.js`  
   - Сердце всей системы. Обрабатывает все REST-эндпоинты, SSE-шину `broadcastEvent`, запись в `ufanet_db.json` и запуск системного Проводника Windows (`explorer.exe`).
   - *Правило:* Не менять структуру ответов и имена полей без одновременного обновления `src/lib/api.js`.

2. `src/App.jsx`  
   - Корневой стейт React: содержит массив `tasks`, `currentUser`, состояние модальных окон, логику Drag&Drop перемещения между колонками и блокировку экрана гостя.
   - *Правило:* Не перегружать тяжелой версткой; выносить UI в специализированные компоненты.

3. `src/lib/constants.js`  
   - Все базовые справочники компании Уфанет: отделы `DEPARTMENTS`, колонки по умолчанию `DEFAULT_COLUMNS`, матрица прав `DEFAULT_PERMISSIONS`, коэффициенты ЗП `KST_OPTIONS`, `KIZM_OPTIONS`, `KSL_OPTIONS`.
   - *Правило:* Сохранять согласованность идентификаторов отделов (`dept-design`, `dept-welding`, `dept-pcc`, `dept-sales-b2b`, `dept-sales-b2c`).

4. `src/lib/api.js`  
   - Клиентский транспорт данных.
   - *Правило:* Всегда обрабатывать ошибки сети `try/catch` и возвращать fallback-значения, чтобы интерфейс не падал в белый экран.
