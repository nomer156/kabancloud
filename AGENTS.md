# ИНСТРУКЦИЯ ДЛЯ AGENTIC AI (ПРАВИЛА РАЗРАБОТКИ И ПОДДЕРЖКИ)

> **Статус:** Обязательный регламент работы любого AI-агента в проекте Уфанет Kaban.

---

## ⚡ ЖЁСТКИЕ ПРАВИЛА РАБОТЫ В ЭТОМ РЕПОЗИТОРИИ

### 1. Сначала изучай архитектуру, а не код подряд
- Перед внесением любых изменений в проект **ВСЕГДА** сверяйся с [PROJECT_MAP.md](PROJECT_MAP.md) и [ARCHITECTURE.md](ARCHITECTURE.md).
- В таблице зон ответственности в `PROJECT_MAP.md` найди требуемый функционал и определи **минимально необходимый набор файлов** (1–3 файла максимум для локальной задачи).

### 2. Запрет на слепое сканирование проекта
- **Никогда** не сканируй весь проект целиком без явной необходимости.
- Не запускай рекурсивные поиски по всей папке `src/`, если файл компонента уже известен из `PROJECT_MAP.md`.
- Читай только те блоки кода, которые относятся к задаче, используя смещения или чтение конкретных строк.

### 3. Явная декларация действий
- В начале каждого шага явно сообщай:
  > **Файлы для анализа:** `[путь/к/файлу]`  
  > **Файлы для изменения:** `[путь/к/файлу]`  
  > **Цель изменения:** `[краткое описание в 1 предложение]`

### 4. Неприкосновенность чужих модулей
- Не трогай и не форматируй файлы и папки, не связанные с текущей задачей.
- Сохраняй все существующие комментарии, JSDoc и сигнатуры функций, не относящихся к правке.

### 5. Поэтапное выполнение сложных задач
- Если задача содержит более двух требований:
  1. Разбей её на изолированные шаги.
  2. Выполняй и валидируй каждый шаг по очереди (`npx oxlint`, `npm run build`).
  3. Не накапливай гигантские неизведанные дифы.

### 6. Обязательная проверка целостности сборки
- После внесения правок запусти:
  ```bash
  npx oxlint <измененные_файлы>
  npm run build
  ```
- Убедись в отсутствии необъявленных переменных (`ReferenceError`) и синтаксических ошибок JSX.

### 7. Четкий отчет о проделанной работе
- После завершения задачи давай краткий отчет:
  - Что именно было изменено и в каких файлах.
  - Почему возникла проблема и как она решена.
  - Команды для обновления рабочей виртуальной машины.
