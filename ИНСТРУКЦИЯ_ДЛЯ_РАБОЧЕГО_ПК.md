## 🏃‍♂️ Как запустить на рабочем ПК

В папке проекта находится готовый командный файл:
👉 **`start.bat`** — запускает сервер и автоматически открывает браузер на `http://localhost:3000`.

### Сценарии окружения на рабочем ПК:

#### Вариант А: На рабочем ПК установлен Node.js
- Просто дважды кликните по **`start.bat`**.
- Скрипт определит системный Node.js, запустит сервер и откроет доску в браузере.

#### Вариант Б: На рабочем ПК НЕТ Node.js и НЕТ прав администратора (Портативный запуск)
Вам **не нужны** права администратора и **не нужно** ничего устанавливать!
1. На домашнем ПК возьмите один единственный файл:
   `C:\nvm4w\nodejs\node.exe`
2. Скопируйте этот файл `node.exe` на флешку и положите прямо в папку проекта на рабочем ПК (рядом с `start.bat` и `server.js`).
3. Запустите `start.bat`. Он автоматически обнаружит портативный `node.exe` и запустит сервер без установки!

#### Вариант В: На рабочем ПК есть Docker
- `start.bat` автоматически определит Docker и запустит контейнер в фоне.

## 🌐 Как открыть доску коллегам из отдела проектирования

Сервер `server.js` работает на всех сетевых интерфейсах (`0.0.0.0`).
1. Узнайте IP-адрес вашего рабочего ПК в локальной сети Уфанет (команда `ipconfig` в консоли, например `10.168.x.x` или `192.168.x.x`).
2. Коллеги из отдела могут открыть в своем браузере:
   `http://ВАШ_IP:3000`
   и полноценно работать с доской (создавать задачи, писать комментарии, упоминать друг друга).

## 💰 Автозаполнение ЗП (ProjectPay) на рабочем ПК

Скрипт v3.0 работает полностью конфиденциально в браузере проектировщика, не отправляет никаких данных на внешние сервера и производит автозаполнение только в момент нажатия кнопки.

### Простая установка в 1 клик на рабочем ПК:
1. Откройте Chrome на рабочем ПК и установите расширение **Tampermonkey** (или **Violentmonkey**) из Chrome Web Store.
2. При запущенной доске перейдите в адресную строку браузера и откройте:
   `http://localhost:3000/projectpay_autofill.user.js`
3. Tampermonkey сам перехватит эту ссылку и откроет окно установки скрипта. Нажмите кнопку **«Установить»** (Install).
4. Всё готово!

Теперь:
- В карточке задачи нажимаете кнопку перехода в ProjectPay.
- Открывается форма ввода на `pp.core.ufanet.ru`.
- Все поля (Название, Шифр, Код, Регион «АО Уфанет Москва», Вид работ, Часы Тфакт, ERP-номер, Коэффициент сложности, Примечание) автоматически заполняются.
- Проектировщик визуально проверяет данные и нажимает «Отправить».

- Запустите файл **`stop.bat`** или закройте черное окно консоли сервера.
